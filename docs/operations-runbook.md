# Operations runbook

## Deploy (single host)
1. DNS → host; put TLS certs in `infra/certs/{fullchain,privkey}.pem` (e.g. certbot).
2. `cp infra/.env.example infra/.env`; set `PUBLIC_ORIGIN`, `POSTGRES_PASSWORD`,
   `STREAM_SIGNING_SECRET` (`openssl rand -base64 32`). Never commit it.
3. `docker compose -f infra/docker-compose.prod.yml up -d --build`
   — `migrate` runs first (one-shot); `api` and `worker` start only after it succeeds.
4. Check: `curl https://<host>/api/../readyz` via `docker compose exec api` or the health check;
   open `/api/docs`.

## Environment (API)
| Var | Default | Notes |
|---|---|---|
| `DATABASE_URL`, `REDIS_URL` | — | required |
| `STREAM_SIGNING_SECRET` | — | ≥32 chars; rotating it invalidates playback tokens (clients refresh automatically) |
| `WEB_ORIGINS` | `http://localhost:3000` | comma list; CSRF origin allow-list + CORS |
| `MUSIC_PROVIDER` | `youtube` | `youtube` \| `dev` — read music-licensing.md |
| `YT_LOCATION` / `YT_LANGUAGE` | `US` / `en` | feed region/language |
| `TRUST_PROXY` | `false` | `true` behind nginx (real client IPs for rate limits) |
| `RATE_LIMIT_PER_MIN` / `STREAM_RATE_LIMIT_PER_MIN` / `AUTH_RATE_LIMIT_PER_MIN` / `PLAYBACK_TOKEN_RATE_LIMIT_PER_MIN` | 600 / 1500 / 10 / 120 | per IP |
| `STREAM_MAX_CONCURRENCY` | 64 | upstream audio fetches per instance (503 beyond) |
| `SESSION_TTL_DAYS` | 30 | |
| `WORKER_INLINE` | `true` | `false` when the separate worker runs |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | unset | enables OpenTelemetry traces + metrics |
Web: `API_ORIGIN` (server-side fetches).

## Health & SLOs
- `/healthz` liveness (no deps) · `/readyz` readiness (Postgres required; Redis/provider reported).
- Suggested SLOs: API availability 99.5 %/30 d; cached catalog p95 < 100 ms; playback start
  (tap → audio) p95 < 2.5 s; event-ingest lag < 5 min.
- Logs: JSON (pino), `X-Request-Id` on every response, cookies/auth redacted, query strings dropped.

## Failure modes
| Symptom | Likely cause | Action |
|---|---|---|
| Everything plays "unavailable" / 502 provider errors | YouTube changed InnerTube or blocked the server IP | update `youtubei.js`/`bgutils-js`; check `/readyz` provider flag; consider another egress IP |
| Audio stops after ~1 MiB | PoToken attestation failing | logs "stream resolve failed"; usually fixed by library update |
| Redis down | — | API keeps working (cache bypass, rate-limit skipOnError); latency rises |
| Postgres down | — | `/readyz` 503; catalog still served from Redis; library/auth fail with clear errors |
| Outbox backlog grows | worker down or poison rows | `select count(*) from outbox_events where processed_at is null`; dead letters have `failed_at` |

## Backups
- `scripts/backup.sh` — `pg_dump -Fc` into `infra/backups/`, keeps 14 (cron daily).
- `scripts/verify-restore.sh <dump>` — restores into a throwaway DB and checks row counts.
  **Verified locally** against the dev database.
- Copy `infra/backups/` off-host (object storage) — not automated here.

## Migrations
Forward-only, generated by `drizzle-kit` (`apps/api/drizzle/`). Before a risky migration: run
`backup.sh`. Rollback = restore the pre-migration dump + redeploy the previous image.
